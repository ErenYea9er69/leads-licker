# Skill pack

One set of skills drives both the pipeline and the MCP server. The text is the same in both places, so a rule changes in one file and applies everywhere.

| Skill | Stage | What it does |
| --- | --- | --- |
| customer-discovery | router | Orders the stages, sets stop rules and the report |
| business-intelligence | profile | Builds the profile: problems, ICP, pain vocabulary, alternatives, not_for |
| community-search | search | Plans queries and reads threads like a long-time member |
| lead-qualification | qualify | Scores a post on a 100-point rubric with verbatim evidence |
| thread-engagement | engage | Picks the reply target: the post or one comment |
| community-copywriting | write | Writes in the owner's voice, applies the pitch ladder and the disclosure |
| platform-safety | safety | Hard limits, platform rules, account health, warm-up |

## File layout

Each skill is a folder with a SKILL.md and a references folder.

- The frontmatter holds name, description, version, stage, used_by and references.
- The block between the lines `<!-- prompt:start -->` and `<!-- prompt:end -->` is the compact text the pipeline puts into API prompts.
- The text after the block is for host AIs and people.
- manifest.json is generated by `python scripts/validate_skills.py --write-manifest`.

## How the pipeline loads them

`agent_reach.discovery.skillpack` reads the folders from the installed package (or from this folder in a source checkout). Each pipeline stage calls `skillpack.prompt("stage skill name")` and adds the compact block to its system prompt. The linter reads the banned word lists and the disclosure phrases from community-copywriting/references.

## How the MCP server loads them

The server serves each skill as a resource (`skill://{name}`) and as a tool (`reach_get_skill`). Prompts such as `discover_leads_workflow` embed the right skills. A host AI loads the router first, then one skill per stage.

## Use the skills in Claude Code or another client

Copy the folders into the client's skills directory, for example `~/.claude/skills/`. The folders work without the Python app. The MCP tools give the skills their data.

## Edit the skills

1. Edit the files.
2. Run `python scripts/validate_skills.py`. It checks frontmatter, markers, word counts, dashes and list formats.
3. Run `pytest tests/test_examples.py`. It lints every good and bad example.
4. Commit. The CI repeats both checks.

Keep prompt blocks between 350 and 650 words. Keep references focused on one topic each.
